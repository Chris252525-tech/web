🔧 Descripción del Proyecto: Sistema de Gestión de Préstamo de Herramientas – UTSOE

Este proyecto tiene como objetivo el desarrollo de una aplicación web enfocada en optimizar la gestión y control de préstamos de herramientas dentro del área de mantenimiento de la Universidad Tecnológica del Suroeste de Guanajuato (UTSOE).

🛠️ Problemática actual

Actualmente, el área de mantenimiento enfrenta diversos problemas operativos y administrativos derivados de la falta de mecanismos formales para registrar y supervisar el uso de herramientas. Esto provoca:

  • Pérdidas de material
  • Uso indebido de equipos
  • Sobrecarga de responsabilidades en el personal encargado de los préstamos

✅ Solución propuesta

El sistema web busca ser una herramienta integral que permita:

  • Registrar de manera eficiente cada préstamo de herramienta
  • Asociar cada herramienta a un responsable (nombre, datos de contacto, fecha de préstamo y devolución)
  • Generar una base de datos confiable para seguimiento y análisis
  • Minimizar errores humanos y pérdidas de inventario
  • Escalar con nuevas funciones conforme evolucionen las necesidades del área

🎯 Beneficios

El sistema brindará mayor control, transparencia y eficiencia en los procesos diarios del personal de mantenimiento, reduciendo los problemas actuales y mejorando la administración de recursos institucionales.
